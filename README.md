# HTG：利用教师内部状态变化改进 on-policy 蒸馏

研究进展汇报｜2026 年 9 月 13 日

## 一、研究目的

标准 on-policy 蒸馏（OPD）的过程是：先让学生自己生成回答，再让教师评价这些回答中各个 token 的概率，据此更新学生。token 是模型处理文本的基本单位，可以是一个字、一个词或词的一部分。我们希望进一步利用教师内部的状态变化信息，提升学生的数学推理能力。

核心问题是：**除了“下一个 token 应该是什么”，教师内部“如何随推理过程改变状态”的信息，能否为学生提供额外的训练信号？**

研究对象为 **Qwen3-8B → Qwen3-1.7B-Base**。提出的 HTG（Hidden Transition Geometry，隐状态转移几何）比较相邻 token 的隐状态变化，并让学生的变化关系接近教师：

这里的三个词具体指：

- **隐状态**：模型某一层在某个 token 位置输出的向量，是该位置的内部表示。
- **转移方向**：相邻位置的隐状态之差，即 `h(t+1) − h(t)`，经中心化和单位化后表示状态往哪个方向变化。它是数学上的向量差，不预设一个 token 就对应一个完整推理步骤。
- **转移几何**：把不同位置的转移方向两两比较，用余弦记录哪些变化同向、哪些相反、哪些接近正交。把这些数排成一张表，就是“关系矩阵”。HTG 要求学生的这张表接近教师。

例如，教师在位置 A 和 B 的状态变化方向很相似，HTG 就鼓励学生在这两个位置的变化方向也相似，而不要求师生的隐向量逐维相等。

这种关系矩阵不要求师生模型的隐层宽度相同，可以作为 OPD 之外的辅助训练目标。

## 二、做过的实验

| 实验 | 做法 | 想回答的问题 |
|---|---|---|
| 内部表征筛选 | 比较注意力模块输出、前馈网络（MLP）输出和整层输出；比较位置本身的向量与相邻位置的向量差 | 哪种内部信息更值得蒸馏？ |
| OPD 前后对比 | 让未蒸馏的初始学生（Base）与 OPD 训练后的学生处理同一批回答，比较内部关系 | 标准 OPD 是否已经学到了这些信息？ |
| HTG 辅助训练 | 在 OPD 上加入转移几何损失，比较正确教师对应与打乱对应 | 内部对齐能否带来数学能力提升？ |
| 几何干预 | 直接修改学生隐状态，使关系矩阵接近教师 | 几何改善是否能改善后续输出？ |
| 行为签名干预 | 比较转移方向对输出概率的影响，并让学生的影响方式接近教师 | 更贴近输出的内部目标是否有效？ |
| 扰动传播分析 | 跟踪干预从中间层到输出层的变化 | 干预是否被后续网络吸收？ |

“正确教师对应”指比较同一回答、同一 token 位置上的师生转移；“打乱对应”指随机重排教师转移与学生转移的配对，用来检查正确位置关系是否重要。

当前主要训练目标取学生第 12 层和教师第 15 层的输出，代码从 0 开始编号，因此记为 S11/T14。每条能提供至少 128 对相邻响应 token 的回答，采样 128 个转移。

## 三、实验结果

**1. 相邻状态变化比静态状态更有区分度。**

在所测层对中，层输出的转移几何能更明显地区分正确教师对应与打乱对应。例如 S11/T14 上，区分度指标从静态表征的约 **0.48** 提升到转移表征的约 **1.74**，因此选择它作为 HTG 的主要目标。

这里的“区分度”定义为 **（打乱对应的损失 − 正确对应的损失）÷ 正确对应的损失**。数值越大，说明打乱位置对应后损失上升得越明显；它衡量对应关系的重要程度，不是准确率或训练收益。

**2. 标准 OPD 对不同内部关系的学习程度不同。**

部分静态关系会随 OPD 自然接近教师，而所选转移几何变化较小。这说明内部关系对齐与输出概率对齐并不完全同步。

**3. 探索性训练尚未显示稳定提点。**

MATH500 的代表性历史结果如下，Avg@8 表示每题采样 8 次后的平均准确率：

| 配置 | MATH500 Avg@8 |
|---|---:|
| 纯 OPD | 61.55% |
| HTG，λ=4.80，一条探索配置 | 60.67% |
| HTG，较小辅助系数 λ=0.03851 | 61.38% |
| HTG，较大辅助系数 λ=0.07700 | 61.30% |
| 打乱教师对应，辅助系数 λ=0.10804 | 61.85% |

λ 是辅助损失前的乘数：总损失 = OPD 损失 + λ × HTG 损失。不同配置的 λ 不直接等于辅助梯度占比。

这些配置尚未形成正确教师关系带来收益的证据。目前正在统一训练实现，重新进行纯 OPD 与 HTG 的比较。

## 四、机制验证

机制实验得到的主要图景是：**内部关系能改好，扰动也能传到输出，但输出变化没有稳定转化为更接近教师。**

### 1. 目标确实可以被改变

这里的“干预”是临时修改某个位置的隐状态，再继续运行模型，观察变化；不更新模型参数。几何干预能够降低师生关系矩阵的差异。

**“行为签名”是本实验给一个测量向量起的名字**：在固定位置，沿该位置的转移方向对隐状态做正、负两个小幅修改，比较修改后各个 token 的 log-prob（概率的对数）。得到的向量描述：沿这个内部方向移动，会让哪些 token 更可能、哪些更不可能，以及变化有多大。

两个模型的隐层宽度不同，但都预测同一套 token，所以可以比较它们对这些 token 概率的影响。这里的“签名余弦”衡量两个影响向量的方向是否相似，越接近 1 越相似。代表性实验中，这个余弦平均提高 **0.251**，16 条回答全部提高。

### 2. 干预并没有被网络完全吸收

逐层跟踪显示，扰动可以传播到后层，并改变输出概率。因此，收益不明显不能简单解释为“中间层改了，但传不到输出”。

### 3. 改善内部一致性，不等于改善输出目标

这里用 **reverse KL，即 KL(p学生 ∥ p教师)** 衡量固定回答前缀下，两种模型下一 token 概率分布的差异，并在后续窗口内取平均。“teacher KL”指以教师分布为参照计算的这个指标，不是另一个新指标。

以均匀采样位置、小步长的代表性实验为例：

| 干预方向 | 签名变化 | 后续 reverse KL 平均变化 |
|---|---|---:|
| 让签名接近教师 | 明显改善 | +0.00052，未显示明确改善 |
| 直接沿 teacher KL 的下降方向 | 不以签名为目标 | −0.01285，明显改善 |

表中的负值表示差异减小，正值表示差异增大。“直接沿 KL 的下降方向”指对隐状态求 KL 梯度，沿负梯度移动，用来确认这个指标确实可以被推动。

我们还选取了师生对实际生成 token 的 log-prob 差值较大的位置，即高 |k1| 位置。在这些位置，签名干预仍未稳定优于随机或打乱教师对应的对照。

**当前机制判断：问题更可能在于“内部匹配目标是否选中了有用的行为方向”，而不仅是“是否把内部目标推得足够接近”。**

## 五、下一步方向

**第一步：完成 HTG 的直接训练验证。**

在同一训练实现和预算下比较纯 OPD 与 HTG，观察是否出现可重复的数学评测提升；若有收益，再通过打乱教师对应的对照判断收益是否来自教师关系本身。

**第二步：让目标选择更直接地围绕行为收益。**

后续优先考虑与 teacher KL 下降方向有明确联系的内部信息，而不是仅按“师生内部关系是否相似”选择目标。机制实验中的直接 KL 下降方向已经证明输出存在可改善空间，关键是找到能够利用这部分空间的辅助信号。

**第三步：根据短跑结果决定投入。**

如果正确 HTG 能稳定优于纯 OPD 和打乱对照，再扩大训练；如果仍无收益，就把重点转向选择哪些 token 更值得向教师学习，以及为这些位置分配多少训练权重，不继续单纯增加几何匹配强度。
